# Branch Sales, Installation & Service KPI Mart

**Dataset is simulated.** Questions are the ones branch leadership actually asks.  
Branches: **Surat, Vadodara, Vapi**.

## Departmental structure
- **Sales**: Leads → Inquiries → Quotations → Agreements (bookings). Employees: Lead Generator, Salesperson, Sales Manager.
- **Installation**: Unit-level tracking (unit_id = BK-YYYY-NNNNNL001). Specs include capacity (1 passenger = 68 kg), speed, floors, openings, door type, grouping, material, license scope. Third-party POs for Erection, Scaffolding, Wiring, Misc. Employees: Installation Engineer, Installation Manager.
- **Service**: Warranty (12/18/24 months) → AMC (Comprehensive / Non-comprehensive) by Service Sales Person. Repair Orders for Non-comprehensive and out-of-portfolio units. Service Supervisor owns RO; Technicians execute. Incentives for all roles.

## Data volume (approximate)
- 4,500 leads → ~880 bookings → 1,700+ units
- 1,600+ AMC contracts
- ~900 repair orders
- Installation POs, warranty, incentives

## Stack
PostgreSQL star schema + Python loader + Power BI / DAX.

## Quick start
1. Run `sql/schema.sql`
2. `python generate_data.py` (already generated; CSVs in `data/`)
3. `python load_postgres.py --db yourdb`
4. Connect Power BI. See `docs/dax_measures.md` and `docs/metric_dictionary.md`.

## Key files
- `generate_data.py` — full synthetic generator
- `data/` — CSVs
- `sql/schema.sql` — star schema
- `docs/` — metric dictionary, requirement note, ERP boundary, DAX
- `dashboard/` — multi-tab KPI dashboard: data build script, aggregated datasets and page source (see `dashboard/README.md`)
- `REPORT.md` — full project report: KPI definitions, findings, recommendations, data quality (generated by `dashboard/build_report.py`)
