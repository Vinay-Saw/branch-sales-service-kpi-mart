# Requirement Note (Stakeholder Language)

**Question leadership asks:**  
“Which branch is off target, and is it a sales problem, an installation problem, or a service problem?”

**What the model answers without a new export:**
1. Sales funnel: leads → inquiries → quotations → won bookings, by branch and salesperson.
2. Installation progress: units by status, third-party PO costs, on-time completion.
3. Service: open repair orders older than SLA, AMC renewals due this month, warranty expiring, Comprehensive vs Non-comprehensive mix.
4. Employee incentives across roles.

**Branch view:** Three branches do not share one number. Use branch slicer or RLS.

**Reconciliation:** Dashboard totals for bookings, units, AMC, and repair orders equal the SQL totals.
